# Real fine-tune anchors: predictor-pick vs bandit-pick

Transfer check for the `prescription_compare` sandbox. Two **pool-selected** pi0 arms
(base 400 + 200), directly comparable to core/random, no GR00T format landmine.
Generated by `prescription_compare/gen_anchor_arms.py` from the RoboCasa twin
(fidelity −0.34). **Hypothesis:** bandanchor (concentrate on collectable-headroom
categories) > predanchor (spread into the retention-toxic grasp cluster).
**Honest scope:** 2 runs, n≈280 eval — a spot-check, not a powered result.

Plans: `weakregion/predanchor_plan.json`, `weakregion/bandanchor_plan.json`.

| group | predanchor | bandanchor |
|---|---|---|
| unfixable_hard (juice/jar/cheese_grater/wine/water_bottle) | 75 | 10 |
| hard_collectable (pitcher/reamer/colander/bottled_water/jug/yogurt/spray) | 55 | **190** |
| retention_toxic (tongs/dish_brush/mug/rolling_pin/…) | 40 | 0 |
| easy_majority (cucumber/corn/…) | 30 | 0 |

```
MG=/data/xinyua11/robocasa_pkg/datasets/v1.0/pretrain/atomic/PickPlaceCounterToSink/20250819/mg/demo/2025-08-20-22-32-27/lerobot
```

## 1. Build arms JSON (reuse the shared 400-base, like every other arm)

```bash
cd /data/xinyua11/robocasa
for arm in predanchor bandanchor; do
  python policy_analysis/build_arms.py \
    --plan   weakregion/${arm}_plan.json \
    --mg_dir "$MG" \
    --base_file weakregion/arms.json \
    --out    weakregion/arms_${arm}.json
done
```

## 2. Build the LeRobot fine-tune datasets (base + selected 200 = 600 eps)

```bash
for arm in predanchor bandanchor; do
  python policy_analysis/build_lerobot_subset.py \
    --src  "$MG" \
    --arms weakregion/arms_${arm}.json \
    --which base+core \
    --dst  /data/xinyua11/ft_arms/ppc2sink_base_${arm}
done
```

## 4. Train (~8 h each on H100)

```bash
cd /data/xinyua11/openpi
python scripts/train.py pi0_ppc2sink_predanchor  --exp_name predanchor_v1
python scripts/train.py pi0_ppc2sink_bandanchor  --exp_name bandanchor_v1
```

## 5. Eval on the SAME stratified protocol as core/random (comparability)

```bash
cd /data/xinyua11/robocasa
for arm in predanchor bandanchor; do
  # serve: cd /data/xinyua11/openpi && python scripts/serve.py pi0_ppc2sink_${arm} --exp_name ${arm}_v1 --step 20000 &
  MUJOCO_GL=egl python policy_analysis/analyze_pi0_weakregions.py \
    --n 300 --seed 100000 --out_dir weakregion/eval_strat_${arm}
done
```

Compare `weakregion/eval_strat_{predanchor,bandanchor}` against the existing
`eval_strat_{core,random,baseline}`. **Expected:** bandanchor ≥ core-level and >
predanchor; predanchor regresses (retention_toxic). If bandanchor beats core, that is a
real (if under-powered) signal that concentrate-on-collectable-headroom transfers.
